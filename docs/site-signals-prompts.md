# Site-signals prompt series

This is an original architectural response to a material-collage reference,
not a remake of its imagery. The external work contributed only generic
observations: tactile pigment on physical surfaces, a monumental silhouette,
and a saturated limited palette.

Excluded from the new work: the source's people wrapped in striped cloth,
painted animals, camel/pyramids, painted mountain, stripe geometry, exact
red/blue swatches, and every source composition.

## Original prompts

```text
three survey crews aligning mirrored prism tripods along a steep unfinished concrete accessibility ramp, low side view, marker flags and coiled cables form angular clusters, the ramp and equipment fill the portrait frame

stacked prefabricated facade cassettes resting on timber trestles in a fabrication hall, each cassette carries oversized irregular inspection patches and circular registration marks, compressed frontal view, no people, dense edge-to-edge arrangement

temporary scaffold tower wrapped in loose wind-testing ribbons and perforated safety mesh, viewed upward from its base, all ribbons pulled strongly toward one side, diagonal braces and fabric fill the portrait frame, no people

compact weather station seen from a high oblique angle, tilted solar panels, sensor masts and instrument boxes arranged in a tight calibrated field on an abstract neutral surface, removable protective covers create repeated color patches, no people
```

Run with `--style site-signals --ar 2:3` and use one fixed seed per tile. Every
PNG receives a JSON receipt containing both the authored prompt and the exact
medium suffix sent to Flux.

## Source boundary

The linked X images are inspection-only. They are never uploaded to ComfyUI,
stored as a shipped reference, or named in a generation prompt. The style
reference is an object-free image generated by `riso.motif`; the palette is a
new project selection. This supports an independent-process claim but is not a
guarantee of exclusive copyright. Flux Redux remains non-commercial.
